# 交易引擎 - OpenCTP 配置指南

## 🚀 快速开始

### 1. 注册 SimNow 账号

访问 SimNow 官网注册测试账号：
- 官网：http://www.simnow.com.cn/
- 注册后会获得：用户名、密码

### 2. 获取最新服务器地址

SimNow 提供多个环境：

**7x24 环境**（推荐用于测试）
- 电信：`180.168.146.187`
- 移动：`218.202.237.33`
- 行情端口：`10131`
- 交易端口：`10130`

**实盘仿真环境**
- 电信：`180.168.146.187`
- 行情端口：`10211`
- 交易端口：`10201`

### 3. 配置文件

编辑 `trading_engine/config.py`:

```python
OPENCTP_CONFIG = {
    "broker_id": "9999",  # SimNow 固定为 9999
    "user_id": "你的账号",  # SimNow 注册的账号
    "password": "你的密码",  # SimNow 注册的密码

    "app_id": "simnow_client_test",
    "auth_code": "0000000000000000",

    # 选择合适的服务器
    "md_address": "tcp://180.168.146.187:10131",
    "td_address": "tcp://180.168.146.187:10130",
}
```

### 4. 运行测试

```bash
python tests/test_openctp.py
```

## 🔍 常见问题排查

### 错误代码 4097 - 连接断开

**原因**：
1. 服务器地址错误或服务器停机维护
2. 账号密码错误
3. 网络连接问题
4. 防火墙阻止

**解决方法**：
1. 检查 SimNow 官网公告，确认服务器地址
2. 确认账号密码正确
3. 尝试其他网络环境（关闭 VPN、切换网络）
4. 检查防火墙设置

### 认证失败

**原因**：
- app_id 或 auth_code 不正确
- 账号未激活

**解决方法**：
- 使用 `simnow_client_test` 作为 app_id
- auth_code 使用 `0000000000000000`（16个0）
- 登录 SimNow 官网确认账号已激活

### 订阅行情无数据

**原因**：
- 合约代码错误
- 行情服务未启动
- 非交易时间（部分环境）

**解决方法**：
- 确认合约代码正确（如 `rb2505` 螺纹钢、`IF2502` 股指期货）
- 7x24 环境应该全天有数据
- 检查是否在交易时间段
