# 数据层体检与补齐规划

> 这是一份**数据地基**文档，回答三个问题：现在有什么数据、对项目够不够用、缺的从哪补。
> 它坐落在 P1-2（数据扩展）/ P2-1（估值模型）这些"能力卡"**脚下**——那些卡是在数据之上建能力，本文管数据本身。

---

## 0. 一句话结论

**A股是满血主战场，港美股是"只有行情、没有基本面"的半残，全项目的新闻/舆情近乎空白。** 日线三市场都到最新交易日、质量可用；真正的短板是**港美股基本面（0 覆盖）+ 新闻情感（≈空）+ 港美股基准指数（无）**，外加一批下游衍生数据卡在 07-09 的 pipeline 债。所有缺口的数据源都已实测通，不存在"补不了"的死角。

---

## 1. 体检口径（先说清楚，数字才可信）

- **数据源**：`/Volumes/T9/Fin/data/market.db`（软链自 `backend/data`），15GB，`PRAGMA quick_check = ok`（完整性无损）。
- **真股票口径**：统计一律用 `stock_type='stock' AND is_active=1`。**不能只看 `is_active`**——港美股的 `excluded_bond_note`/`excluded_rmb_counter`/`excluded_leveraged_etf` 的 `is_active` 全是 1，光看它会把分母虚高 1600+。
- **新鲜度不用 `max(date)`**：项目已有正确口径 `common/market_freshness.py`（各市场按自己稳态中位数 ×0.8 定"参考交易日"）。本文沿用它，不用绝对日期线（那样会把港美股正常的 T+1 时区差误判成陈旧）。

### 隐藏问题（不在表面覆盖率里，但会咬人）
1. **`adjust_factor` 字段三市场全空**。价格本身是复权的（能用），但因子没存 → 无法反推原始价、无法定位精确除权点。
2. **两套复权口径不一致**：A股 `qfq`（前复权，`acquisition/markets/china_hist.py:94`）vs 港美 yfinance `auto_adjust=True`（`acquisition/markets/overseas.py`）。各市场独立回测没问题，**跨市场组合回测的基准归一会有细微偏差**。
3. **前复权价会漂移**：A股 qfq 的基准是最新价，历史 K 线每天都在微变。个人回测可接受，但要知道这回事。

## 3. 够不够用——按引擎需求逐个判

对着 `docs/ARCHITECTURE.md` 每个引擎的实际数据输入判：

### ✅ 数据够，能满血
- **A股全链**：技术分析 / 信号 / 回测 / 基本面选股 / cockpit 五维 / 涨停预测。A股是项目的主战场，财务10年+、行业全、基准全——**没有短板**。
- **三市场的技术面 + 回测**：日线齐全且复权，C++ 回测的信号驱动策略能跑。

### 🟡 降级能跑（缺一部分维度）
- **cockpit 五维打分**：技术/持仓维三市场都行；**基本面维港美股是空的**；**情感维三市场几乎全空**（没新闻）。→ 港美股的 cockpit 实际只有 2/5 维在工作。P0-2 的 `not_supported` 不扣分设计是给这个兜底的，但兜底 ≠ 有数据。

### ❌ 港美股基本做不了
- **港美股基本面选股**（screener_engine）：0 财务 0 估值，多因子无米下锅。
- **港美股回测基准对比**：无恒指/标普/纳指，"跑赢大盘没有"答不了。
- **新闻/情感整条线**（news_engine）：全项目近乎空数据，情感维形同虚设。

## 6. 补齐规划（三步走，从省事到费事）

### 第一步 · 补下游断档【纯止血，最省事】
- **做什么**：跑一次 `daily_pipeline_scheduler` 的链，把信号/估值/涨停池从 07-09 追平到最新。
- **唯一要改**：信号回补 `lookback_days=5` 是**自然日**（`daily_pipeline_scheduler.py:468` → `detect_signal_gaps` cutoff=`now-timedelta(days=5)`），07-10 卡在窗口外补不回，需手动放大到能盖住断档。
- **成本**：跑一次。**收益**：A股主战场立刻恢复满血。
- **依赖**：无。**建议最先做。**

### 第二步 · 港美股基本面 + 估值 + 行业 + 基准【一张新卡，激活港美股】
- **做什么**：
  - 港美股财务：新增 `acquisition/markets/financial_overseas.py`（akshare 东财港美接口），`FetcherFactory` 按市场路由。
  - 港美股估值/行业/上市日：**yfinance `.info` 一次调用铺满**，落 `stock_valuations` + 回填 `stock_info` 的 sector/industry/list_date。
  - 港美股基准：建 4 个指数（^HSI/^GSPC/^IXIC/^DJI）进 `stock_info`+`daily_quotes`。
- **成本**：中。**收益**：港美股的 cockpit 基本面维、选股、回测基准全部激活。
- **依赖**：无（数据源全通）。**这一步等于把 P1-2 的 C 段 + P2-1 的第0步数据地基一起落实。**

### 第三步 · 新闻/舆情【P1-5 NewsNow，已定稿】
- **做什么**：补全情感维这条全项目最空的线。
- **成本**：中。**依赖**：无（爬虫配置已侦查好，见 P1-2 A 段）。

## 8. 风险与遗留（数据层的"定时炸弹"）

1. **T9 是 exFAT + 库开 WAL**：exFAT 无日志，WAL 依赖 `-shm` 的 mmap。拔盘/盘休眠打断写入 = **文件系统级损坏，SQLite 救不了**。而当前**15GB 库无有效备份**（`market.db.backup` 是2月的360KB，backups目录只有974字节json）。→ **建议：定期 `VACUUM INTO` 冷备到启动盘或另一分区。**
2. **T9 未挂载时后端起不来**：`database.py:22` 的 `mkdir(exist_ok=True)` 会在 import 阶段抛 `FileExistsError`（已实测）。好处是不会静默写空库，坏处是报错跟"硬盘没插"八竿子打不着。→ **建议：加一句挂载检查，报人话。**
3. **`lookback_days=5` 是自然日的洞**：断更 > 5 自然日的交易日会永久掉出回补窗口。第一步会手动补，但**根治要改成交易日口径或大幅放宽**。
4. **`adjust_factor` 全空 + 复权口径不一**：见 §2 隐藏问题，P2-b 处理。

## 附：本次体检的可复现命令（口径固化，下次直接跑）

```sql
-- 真股票口径的各市场最新交易日分布
CREATE TEMP TABLE stk AS SELECT symbol, market FROM stock_info WHERE stock_type='stock' AND is_active=1;
CREATE TEMP TABLE last AS SELECT dq.symbol, MAX(dq.date) d FROM daily_quotes dq
  WHERE dq.symbol IN (SELECT symbol FROM stk) GROUP BY dq.symbol;
SELECT s.market, l.d, COUNT(*) n FROM stk s JOIN last l ON l.symbol=s.symbol
GROUP BY s.market, l.d ORDER BY s.market, l.d DESC;
```
（15GB 全表扫描约 2-4 分钟，走 USB 慢属正常。）
