# 股价预测功能设计方案

## Context

当前 Fin 项目已有完整的数据引擎、分析引擎、回测引擎等模块，但缺少 ML 预测能力。新增一个股价预测功能，要求：
- **预测目标**：既预测涨跌方向，又预测具体价格走势
- **技术方案**：多模型集成（LSTM + XGBoost）
- **展示方式**：独立预测页面

## 整体架构

```
用户输入股票代码
       ↓
  获取历史数据 (data_engine)
       ↓
  特征工程 (技术指标 + 价量特征)
       ↓
  ┌─────────────┬──────────────┐
  │ LSTM 模型   │ XGBoost 模型 │
  │ (价格序列)  │ (涨跌分类)   │
  └──────┬──────┴──────┬───────┘
         ↓             ↓
      集成融合 (加权平均)
         ↓
  预测结果 (方向 + 价格 + 置信度)
         ↓
  前端可视化展示
```

## 一、后端 — prediction_engine 模块

### 1.1 目录结构

```
backend/prediction_engine/
├── __init__.py
├── engine.py              # 预测引擎主入口
├── features.py            # 特征工程
├── validator.py           # 预测验证（回填 + 评估指标）
├── models/
│   ├── __init__.py
│   ├── base.py            # 模型基类
│   ├── lstm_model.py      # LSTM 价格预测模型 (PyTorch)
│   └── xgboost_model.py   # XGBoost 涨跌分类模型
├── ensemble.py            # 多模型集成
└── saved_models/          # 训练好的模型文件存放目录
```

### 1.2 特征工程 (`features.py`)

从现有 `analysis_engine/indicators/` 复用技术指标，构建特征矩阵：

**价量特征**：open, high, low, close, volume 的滞后值（lag 1~20）、收益率、波动率

**技术指标特征**：MA5/10/20/60、EMA、MACD(DIF/DEA/Hist)、RSI、KDJ、布林带、ATR、OBV

**衍生特征**：5/10/20 日收益率、振幅、换手率变化、量比

复用文件：`backend/analysis_engine/indicators/trend.py`, `momentum.py`, `volatility.py`, `volume.py`

### 1.3 LSTM 模型 (`models/lstm_model.py`)

- **用途**：预测未来 N 天的收盘价序列
- **框架**：PyTorch
- **架构**：2 层 LSTM + Dropout + 全连接层
- **输入**：过去 60 个交易日的标准化特征序列 (60 × feature_dim)
- **输出**：未来 N 天的预测价格 (N × 1)
- **训练**：滑动窗口切分样本，80% 训练 / 20% 验证，MinMaxScaler 归一化

### 1.4 XGBoost 模型 (`models/xgboost_model.py`)

- **用途**：预测未来 N 天的涨跌方向（分类）
- **框架**：xgboost
- **输入**：当日特征向量 (1 × feature_dim)
- **输出**：涨跌概率 (prob_up)，direction = UP if prob > 0.5 else DOWN
- **训练**：标签为未来 N 天收益率是否 > 0，Walk-Forward 验证防止未来数据泄露

### 1.5 集成融合 (`ensemble.py`)

- LSTM 输出预测价格序列 → 计算预测收益率 → 得到方向判断
- XGBoost 输出涨跌概率 → 得到方向判断
- **融合策略**：
  - 方向：加权投票（LSTM 0.4 + XGBoost 0.6），XGBoost 对方向分类更擅长
  - 价格：以 LSTM 预测价格为主
  - 置信度：两模型一致时置信度高，不一致时降低

### 1.6 预测引擎 (`engine.py`)

核心类 `PredictionEngine`，提供：
- `train(symbol, period)` — 训练模型（拉取数据 → 特征 → 训练 LSTM + XGBoost）
- `predict(symbol, forward_days)` — 生成预测（加载模型 → 特征 → 推理 → 集成）
- `get_model_info(symbol)` — 查询已训练模型的信息（训练时间、数据量、验证指标等）
- 模型文件保存到 `backend/prediction_engine/saved_models/` 目录

### 1.7 预测验证器 (`validator.py`)

新增 `backend/prediction_engine/validator.py`，负责预测结果的回填与评估：

**自动回填机制：**
- `backfill_outcomes()` — 扫描所有已到期但未回填的预测记录，拉取实际价格，计算实际收益率，判定 WIN/LOSS
- 集成到 APScheduler 定时任务，每日收盘后自动执行
- 回填逻辑：预测日期 + forward_days ≤ 今天 且 actual_return 为 NULL 的记录

**评估指标计算：**
- `calc_performance(symbol?, date_range?)` — 按股票/时间段统计预测表现

| 指标 | 说明 |
|------|------|
| 方向准确率 | 预测涨跌方向的命中率 |
| 价格 MAE | 预测价格与实际价格的平均绝对误差 |
| 价格 RMSE | 预测价格与实际价格的均方根误差 |
| 置信度校准 | 按置信度分桶（0.5-0.6, 0.6-0.7, ...），统计每桶实际准确率，看是否与置信度匹配 |
| 分模型准确率 | LSTM、XGBoost 各自的方向准确率，便于对比谁更靠谱 |
| 连续正确/错误 | 当前连续命中/连续失误的次数 |
| 累计盈亏模拟 | 假设每次按预测方向操作，累计收益曲线 |

### 1.8 数据库模型

在 `backend/data_engine/storage/models.py` 新增 `PredictionRecord` 表：

```python
class PredictionRecord(Base):
    __tablename__ = "prediction_records"
    id              = Column(Integer, primary_key=True)
    symbol          = Column(String(20), index=True)
    prediction_date = Column(Date, index=True)       # 做预测的日期
    target_date     = Column(Date, index=True)       # 预测到期日（prediction_date + forward_days 个交易日）
    forward_days    = Column(Integer, default=5)
    direction       = Column(String(10))              # UP / DOWN
    confidence      = Column(Float)                   # 0~1
    predicted_prices= Column(Text)                    # JSON: [p1, p2, ..., pN]
    predicted_return= Column(Float)                   # 预测收益率
    lstm_detail     = Column(Text)                    # JSON: LSTM 模型细节
    xgb_detail      = Column(Text)                    # JSON: XGBoost 模型细节
    actual_prices   = Column(Text, nullable=True)     # JSON: 回填的实际价格 [p1, p2, ..., pN]
    actual_return   = Column(Float, nullable=True)    # 回填实际收益
    outcome         = Column(String(10), nullable=True)# WIN/LOSS
    created_at      = Column(DateTime, server_default=func.now())
```

新增 `TrainedModelRecord` 表，记录每次训练的模型信息：

```python
class TrainedModelRecord(Base):
    __tablename__ = "trained_models"
    id              = Column(Integer, primary_key=True)
    symbol          = Column(String(20), index=True)
    model_type      = Column(String(20))              # lstm / xgboost / ensemble
    train_period    = Column(String(20))              # 训练数据周期，如 "2y"
    data_points     = Column(Integer)                 # 训练样本数
    train_start     = Column(Date)                    # 训练数据起始日期
    train_end       = Column(Date)                    # 训练数据截止日期
    val_metrics     = Column(Text)                    # JSON: 验证集指标 {mse, mae, accuracy, ...}
    model_path      = Column(String(500))             # 模型文件路径
    status          = Column(String(20), default="ready")  # ready / training / failed
    created_at      = Column(DateTime, server_default=func.now())
```

## 七、验证方式

1. 启动后端：`conda run -n quant python -m uvicorn api.main:app --host 0.0.0.0 --port 8000`
2. 启动前端：`cd frontend && npm run dev`
3. **训练流程**：进入「模型训练」Tab → 输入股票代码 → 选训练周期 → 点击训练 → 观察流式进度 → 训练完成查看指标
4. **预测流程**：进入「预测分析」Tab → 输入已训练的股票 → 点击预测 → 查看图表和预测结果
5. **验证流程**：进入「预测验证」Tab → 点击手动回填 → 查看成绩总览、对比图、置信度校准图
6. **自动回填**：确认定时任务每日执行，检查到期预测是否被自动回填
