# 数据库设计文档

## 1. 概述

### 1.1 数据库选型

#### SQLite (主要存储)
- **优势**: 轻量级、无需配置、文件型、跨平台
- **用途**: 行情数据、交易记录、回测结果
- **适合**: 个人使用、中小规模数据

#### DuckDB (可选 - 分析型)
- **优势**: 列式存储、OLAP 性能优秀、兼容 SQL
- **用途**: 大量历史数据分析、复杂查询
- **适合**: 需要高性能分析时

### 1.2 设计原则
- **规范化**: 减少数据冗余
- **索引优化**: 关键字段建立索引
- **分区存储**: 按时间分区(可选)
- **数据完整性**: 外键约束、唯一约束
- **可扩展性**: 预留扩展字段

## 3. 表结构设计

### 3.1 股票基本信息表 (stock_info)

```sql
CREATE TABLE stock_info (
    symbol VARCHAR(20) PRIMARY KEY,        -- 股票代码
    name VARCHAR(100) NOT NULL,            -- 股票名称
    market VARCHAR(20) NOT NULL,           -- 市场 (a_share, hk_stock, us_stock)
    exchange VARCHAR(10),                  -- 交易所 (SH, SZ, HK, NYSE, NASDAQ)
    industry VARCHAR(50),                  -- 行业
    sector VARCHAR(50),                    -- 板块
    stock_type VARCHAR(20),                -- 股票类型 (主板, 创业板, 科创板)
    list_date DATE,                        -- 上市日期
    is_active INTEGER DEFAULT 1,           -- 是否活跃 (1: 活跃, 0: 退市)
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,

    INDEX idx_market (market),
    INDEX idx_industry (industry),
    INDEX idx_is_active (is_active)
);
```

### 3.2 日线行情表 (daily_quotes)

```sql
CREATE TABLE daily_quotes (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    symbol VARCHAR(20) NOT NULL,           -- 股票代码
    market VARCHAR(20) NOT NULL,           -- 市场
    date DATE NOT NULL,                    -- 交易日期

    -- OHLCV
    open REAL NOT NULL,                    -- 开盘价
    high REAL NOT NULL,                    -- 最高价
    low REAL NOT NULL,                     -- 最低价
    close REAL NOT NULL,                   -- 收盘价
    volume REAL NOT NULL,                  -- 成交量

    -- 扩展字段
    amount REAL,                           -- 成交额
    turnover REAL,                         -- 换手率
    adjust_factor REAL,                    -- 复权因子

    -- 元数据
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,

    -- 唯一约束
    UNIQUE (symbol, date),

    -- 索引
    INDEX idx_symbol (symbol),
    INDEX idx_date (date),
    INDEX idx_symbol_date (symbol, date),
    INDEX idx_market_date (market, date),

    -- 外键
    FOREIGN KEY (symbol) REFERENCES stock_info(symbol)
);
```

**数据验证触发器:**
```sql
CREATE TRIGGER validate_ohlc_before_insert
BEFORE INSERT ON daily_quotes
FOR EACH ROW
BEGIN
    -- 检查 OHLC 关系
    SELECT CASE
        WHEN NEW.high < NEW.low THEN
            RAISE(ABORT, 'high must be >= low')
        WHEN NEW.high < NEW.open THEN
            RAISE(ABORT, 'high must be >= open')
        WHEN NEW.high < NEW.close THEN
            RAISE(ABORT, 'high must be >= close')
        WHEN NEW.low > NEW.open THEN
            RAISE(ABORT, 'low must be <= open')
        WHEN NEW.low > NEW.close THEN
            RAISE(ABORT, 'low must be <= close')
    END;
END;
```

## 4. 数据库初始化

```python
# database.py
from sqlalchemy import create_engine
from sqlalchemy.orm import sessionmaker, scoped_session
from sqlalchemy.ext.declarative import declarative_base

# SQLite 数据库
DATABASE_URL = "sqlite:///./data/market.db"

engine = create_engine(
    DATABASE_URL,
    connect_args={"check_same_thread": False},
    echo=False
)

SessionLocal = sessionmaker(autocommit=False, autoflush=False, bind=engine)
Base = declarative_base()

def init_db():
    """初始化数据库"""
    Base.metadata.create_all(bind=engine)
    print("Database initialized successfully")

def get_db():
    """获取数据库会话"""
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()
```

## 5. ORM 模型示例

```python
# models.py
from sqlalchemy import Column, Integer, String, Float, Date, DateTime, Text, ForeignKey
from sqlalchemy.sql import func
from database import Base

class StockInfo(Base):
    __tablename__ = "stock_info"

    symbol = Column(String(20), primary_key=True)
    name = Column(String(100), nullable=False)
    market = Column(String(20), nullable=False, index=True)
    exchange = Column(String(10))
    industry = Column(String(50), index=True)
    sector = Column(String(50))
    stock_type = Column(String(20))
    list_date = Column(Date)
    is_active = Column(Integer, default=1, index=True)
    created_at = Column(DateTime, server_default=func.now())
    updated_at = Column(DateTime, server_default=func.now(), onupdate=func.now())

class DailyQuote(Base):
    __tablename__ = "daily_quotes"

    id = Column(Integer, primary_key=True, autoincrement=True)
    symbol = Column(String(20), ForeignKey("stock_info.symbol"), nullable=False, index=True)
    market = Column(String(20), nullable=False, index=True)
    date = Column(Date, nullable=False, index=True)
    open = Column(Float, nullable=False)
    high = Column(Float, nullable=False)
    low = Column(Float, nullable=False)
    close = Column(Float, nullable=False)
    volume = Column(Float, nullable=False)
    amount = Column(Float)
    turnover = Column(Float)
    adjust_factor = Column(Float)
    created_at = Column(DateTime, server_default=func.now())
    updated_at = Column(DateTime, server_default=func.now(), onupdate=func.now())

    __table_args__ = (
        {'sqlite_autoincrement': True}
    )
```

def archive_old_data(cutoff_date: str):
    """归档旧数据"""
    # 导出到归档文件
    with engine.connect() as conn:
        df = pd.read_sql(
            f"SELECT * FROM daily_quotes WHERE date < '{cutoff_date}'",
            conn
        )
        df.to_parquet(f"./archive/daily_quotes_{cutoff_date}.parquet")

    # 删除已归档数据
    with engine.connect() as conn:
        conn.execute(f"DELETE FROM daily_quotes WHERE date < '{cutoff_date}'")

### 9.2 分区查询

```python
def get_quotes_by_date_range(symbol: str, start_date: str, end_date: str):
    """按日期范围查询(优化版)"""
    query = """
    SELECT * FROM daily_quotes
    WHERE symbol = :symbol
      AND date BETWEEN :start_date AND :end_date
    ORDER BY date
    """
    with engine.connect() as conn:
        return pd.read_sql(query, conn, params={
            "symbol": symbol,
            "start_date": start_date,
            "end_date": end_date
        })
```

## 11. 总结

数据库设计要点:
1. **表结构规范**: 遵循范式,减少冗余
2. **索引优化**: 关键查询字段建立索引
3. **数据完整性**: 外键约束、唯一约束、触发器
4. **性能优化**: 批量操作、连接池、分区查询
5. **备份恢复**: 定期备份、归档策略

数据库是系统的数据基石,设计需要兼顾性能、可靠性和可维护性。
