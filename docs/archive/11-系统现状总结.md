# 系统现状总结

> 最后更新：2026-02-10

---

## 1. 系统概览

个人量化交易平台，Python 后端 + React 前端，当前主要覆盖 **A 股市场**。

**核心能力**：数据采集 → 技术分析 → 信号生成 → 信号追踪验证 → 策略回测 → 模拟交易

**运行环境**：
- conda 虚拟环境 `quant`，Python 3.12+
- 后端：FastAPI + SQLite（SQLAlchemy ORM）
- 前端：React 19 + TypeScript + TailwindCSS + Vite
- 启动脚本：`bash restart.sh`（自动重启前后端）

## 4. 已实现功能

### 4.1 数据引擎

**数据源**：东方财富 API（通过自研 EastMoneyCrawler）

**EastMoneyCrawler 特性**：
- 浏览器指纹随机化（UA、Accept、语言等）
- 自适应限流检测 + 指数退避
- Session 自动维护
- 代理 IP 支持（快代理 API）

**ProxyManager 特性**：
- 按需获取代理 IP（每次 1 个）
- 自动检测过期，失效立即切换
- 支持认证代理

**全市场增量更新**（`DailyUpdater`）：
- 探测 API 最新可用交易日，智能跳过已最新的股票
- 增量拉取：只请求每只股票 DB 中缺失的日期范围
- 流式进度推送（NDJSON）
- 代理自动切换：超时 8 秒立即换 IP，不重试
- 每 800 只主动换 IP

**数据规模**：
- A 股全市场约 5187 只活跃股票
- 日线数据从 2024-01-01 起

### 4.2 信号生成

**4 个内置策略**：

| 策略 | 买入条件 | 卖出条件 |
|------|----------|----------|
| MA 均线交叉 | 短期均线上穿长期均线 | 短期均线下穿长期均线 |
| MACD | DIF 上穿 DEA | DIF 下穿 DEA |
| KDJ | K 值超卖区回升 | K 值超买区回落 |
| RSI | RSI < 30 回升 | RSI > 70 回落 |

**信号输出**：
```json
{
  "symbol": "000001.SZ",
  "signal_type": "BUY",
  "strength": 0.75,
  "price": 11.05,
  "stop_loss": 10.50,
  "take_profit": 12.16,
  "strategy": "MACD",
  "reasons": [
    {"indicator": "MACD", "detail": "DIF上穿DEA，零轴下方金叉"}
  ]
}
```

**全市场扫描**：
- 流式处理 5000+ 只股票
- 前端实时进度条（rAF 节流）
- 数据新鲜度检查：过期时提示先更新行情

### 4.3 信号追踪验证

追踪每个信号生成后的实际市场表现：

**追踪指标**：
- N 日收益率：1日、3日、5日、10日、20日
- MFE（最大浮盈）和 MAE（最大浮亏）
- 止损/止盈触发情况
- 结果判定：WIN（10日收益 > 1%）/ LOSS（< -1%）/ NEUTRAL

**策略维度聚合**：
- 按策略统计胜率、平均收益、止损止盈率
- 策略对比表格，高胜率策略高亮

### 4.4 策略回测

**回测参数**：
- 初始资金（默认 100 万）
- 手续费率、滑点
- 策略类型 + 参数配置
- 回测日期范围

**绩效指标**：
- 总收益率、年化收益率
- 最大回撤、回撤持续时间
- 夏普比率、索提诺比率
- 胜率、盈亏比
- 逐日净值曲线、交易记录

### 4.5 模拟交易

- 初始化账户（默认 100 万）
- 提交买卖订单（市价/限价）
- 持仓管理、盈亏计算
- 风控规则内置（单股 ≤ 20%、日亏 ≤ 3%、总仓 ≤ 80%、强制止损 -5%）

### 4.6 实时行情

- 全市场实时快照（东方财富数据源）
- 板块筛选：沪市主板、深市主板、创业板、科创板
- 排序：涨跌幅、成交额、换手率
- 分页浏览

### 4.7 AI 分析报告

- 基于 OpenAI API（GPT-4o）
- 自动收集市场数据 + 信号表现
- 流式生成 Markdown 报告
- 支持周报/月报

## 8. 日常使用流程

### 每日操作（推荐顺序）

```
1. 更新行情数据
   信号追踪页 → 点击「更新行情」→ 等待全市场增量更新完成

2. 扫描今日信号
   信号分析页 → 点击「获取今日信号」→ 查看买卖信号

3. 更新追踪数据
   信号追踪页 → 点击「更新追踪」→ 计算历史信号的实际表现

4. 分析策略表现
   信号追踪页 → 查看策略对比表 → 关注胜率 > 60% 的策略

5. 选股决策
   信号分析页 → 筛选高强度(≥0.7) + 优势策略的买入信号
   K 线分析页 → 查看候选股票的技术形态

6. 模拟交易
   交易页 → 下单买入/卖出 → 跟踪持仓盈亏
```

# 一键启动

## 9. 关键设计决策

### 数据获取必须走代理
东方财富会对请求 IP 进行频繁封锁，无论是直接调 API 还是通过 Akshare，底层都是东方财富数据源。所有数据获取操作必须使用代理 IP（快代理）。

### 流式进度推送
信号扫描和行情更新都涉及 5000+ 只股票，耗时较长。采用 NDJSON 流式推送 + 前端 requestAnimationFrame 节流的三层方案：
1. 后端按间隔 yield JSON 行
2. FastAPI StreamingResponse + `await asyncio.sleep(0)` 确保及时 flush
3. 前端 rAF 节流，避免高频 setState 导致卡顿

### 信号追踪与数据更新解耦
- 行情数据更新：信号追踪页的「更新行情」按钮
- 信号扫描：信号分析页的「获取今日信号」（纯 DB 扫描，秒级）
- 追踪更新：信号追踪页的「更新追踪」

三个操作独立，按需执行。

### 日期智能判断
增量更新器通过探测高流动性股票（平安银行）确定 API 最新可用交易日，而非简单使用 `date.today()`。避免在盘前/盘中请求不存在的数据。
