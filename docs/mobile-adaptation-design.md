# 移动端适配设计方案

> 目标：在保持桌面端 UI 不变的前提下，通过 Tailwind 响应式断点适配手机屏幕（< 768px）
> 访问方式：手机连同一个 WiFi，浏览器输入 `http://<电脑IP>:5173`

---

## 一、Layout 布局改造（核心）

**文件：** `components/layout/Layout.tsx`

### 问题
- 侧边栏用 `hover:w-64` 展开，手机没有 hover 事件，完全不可用
- 13 个导航项在侧边栏里太多

### 方案
桌面端保持不变，手机端（`md` 断点以下）改为 **底部 Tab 栏 + 更多菜单**：

```
┌──────────────────────────────┐
│                              │
│        主内容区域             │
│     (全屏宽，无侧边栏)       │
│                              │
│                              │
├──────────────────────────────┤
│ ⚡   📈   🎯   💬   ···     │  ← 底部 Tab 栏（5 个位置）
│ 行情  K线  信号  顾问  更多   │
└──────────────────────────────┘
```

**细节：**
- 底部固定 5 个 Tab：实时行情、K线分析、信号分析、AI 顾问、更多（···）
- 点击「更多」弹出一个底部抽屉面板，展示其余 9 个页面入口
- Tab 栏高度约 56px，带 `safe-area-inset-bottom` 适配 iPhone 底部安全区
- 桌面端：`hidden md:flex`（隐藏 Tab 栏）
- 手机端：`flex md:hidden`（隐藏侧边栏）

**底部 Tab 选取依据（最常用 4 个 + 更多）：**
1. 实时行情 ⚡ — 看盘入口
2. K线分析 📈 — 个股分析
3. 信号分析 🎯 — 核心功能
4. AI 顾问 💬 — 随时问答
5. 更多 ··· — 其余所有页面

---

## 二、通用模式适配规则

以下是所有页面共享的通用适配规则，避免每个页面重复说明。

### 2.1 页面标题栏

**桌面端现状：**
```
[标题文字]                    [按钮1] [按钮2] [更新时间]
```

**手机端改为：**
```
[标题文字]
[按钮1] [按钮2]               [更新时间]
```
- 标题和按钮组分两行：`flex-col md:flex-row`
- 标题字号缩小：`text-xl md:text-2xl` 或 `text-2xl md:text-3xl`
- 按钮缩小 padding：`px-3 py-1.5 text-sm md:px-5 md:py-2`

### 2.2 统计卡片网格

**桌面端：** `grid-cols-4` 或 `grid-cols-5`
**手机端：** `grid-cols-2`（每行两个），重要数据卡片可 `col-span-2` 占满一行

```
桌面: [卡片1] [卡片2] [卡片3] [卡片4] [卡片5]
手机: [卡片1] [卡片2]
      [卡片3] [卡片4]
      [   卡片5（全宽）  ]
```

- 卡片内 padding：`p-3 md:p-6`
- 数字字号：`text-xl md:text-2xl` 或 `text-2xl md:text-3xl`

### 2.3 数据表格

**桌面端：** 完整表格，所有列可见
**手机端：** 两种策略（按场景选择）

**策略A — 卡片化（推荐，用于持仓、交易记录等核心数据表）：**
```
┌────────────────────────┐
│ 股票名 ○○○    涨跌幅   │
│ 代码            现价    │
│ 成交额 | 换手率 | 量比  │
└────────────────────────┘
```
- 手机端隐藏 `<table>`，显示卡片列表
- `hidden md:table` + `md:hidden`（条件切换）

**策略B — 横向滚动（用于数据密集但低频查看的表格）：**
- 保持 `overflow-x-auto`，首列（股票名）sticky 固定
- `sticky left-0 bg-dark-card z-10`

### 2.4 筛选/过滤工具栏

**桌面端：** 一行横排
**手机端：** 换行或折叠

- 搜索框全宽：`w-full md:w-48`
- 板块按钮组换行：`flex-wrap`
- 排序选择器隐藏文字只显示图标，或用 `<select>` 下拉替代按钮组

### 2.5 全局间距

- 页面容器 padding：`p-3 md:p-6`
- 卡片间距：`gap-2 md:gap-4` 或 `gap-3 md:gap-4`
- 组件间距：`space-y-3 md:space-y-6`

### 2.6 底部 Tab 栏留白

所有页面底部需要额外的 padding，避免内容被底部 Tab 栏遮挡：
- `pb-20 md:pb-0`（约 80px，足够覆盖 Tab 栏 + 安全区）

## 三、各页面适配细节

### 3.1 实时行情 (Realtime.tsx) ⭐ 最常用

**大盘指数卡片：**
- 桌面：`grid-cols-4` → 手机：`grid-cols-2`
- 指数价格字号：`text-lg md:text-2xl`

**市场统计（上涨/下跌/平盘/涨停/跌停）：**
- 桌面：`grid-cols-5` → 手机：`grid-cols-5`（保持，但缩小内 padding）
- 这 5 个数字卡片很窄，`grid-cols-5` 在手机上也可以，改为 `p-2 text-center`

**股票列表表格：**
- 采用 **策略A 卡片化**
- 每张卡片展示：名称+代码、现价、涨跌幅、成交额
- 涨跌幅用背景色块突出显示（红涨绿跌）

**筛选工具栏：**
- 搜索框独占一行全宽
- 板块按钮 + 排序按钮第二行 `flex-wrap`
- 分页器简化：只显示「上一页 / 下一页」，不显示具体页码

---

### 3.2 K线分析 (Market.tsx) ⭐

**K线图表区：**
- 图表容器全宽，高度适配：`h-[50vh] md:h-[60vh]`
- Lightweight Charts 原生支持触摸手势（缩放、拖动），无需额外处理

**指标配置面板 (IndicatorPanel)：**
- 桌面端可能是侧栏或弹窗
- 手机端改为底部抽屉（点击按钮展开/收起）
- 或简化为一行 toggle 按钮：`[MA] [MACD] [RSI] [BOLL]`

**股票输入 + 日期选择：**
- 手机端竖排：输入框全宽 + 日期选择器全宽
- `flex-col md:flex-row`

---

### 3.3 信号分析 (Signals.tsx)

**统计卡片：**
- 已有 `grid-cols-1 md:grid-cols-4`，无需改动

**信号列表：**
- 采用 **卡片化**
- 每张卡片：股票名+代码、信号类型（BUY/SELL 标签）、强度、日期、关键理由

**筛选区域：**
- 股票输入 + 日期范围 + 信号类型 竖排排列

---

### 3.4 信号追踪 (SignalTracking.tsx)

- 与信号分析类似的卡片化处理
- 追踪状态用彩色标签显示

---

### 3.5 策略回测 (Backtest.tsx)

**参数配置区：**
- 手机端竖排排列所有输入项
- 每个输入框全宽

**回测结果：**
- 绩效指标卡片：`grid-cols-2`
- 资金曲线图表：全宽，`h-[40vh]`
- 交易记录表：卡片化

---

### 3.6 AI 报告 (Reports.tsx)

- Markdown 渲染内容天然适配小屏（文本流式布局）
- 表格部分加 `overflow-x-auto`
- 报告选择列表改为全宽卡片
- 生成按钮区域竖排

---

### 3.7 AI 顾问 (Advisor.tsx)

**聊天界面：**
- 天然适合手机！聊天消息流 + 底部输入框
- 输入框贴底：`fixed bottom-[56px]`（在 Tab 栏上方）
- 消息气泡宽度：`max-w-[85%] md:max-w-[70%]`

---

### 3.8 交易记录 (Portfolio.tsx)

**统计卡片：**
- 桌面 `grid-cols-5` → 手机 `grid-cols-2`，第 5 个卡片 `col-span-2` 居中

**持仓表格：**
- 卡片化（9 列太多，手机上表格完全不可读）
- 每张持仓卡片展示：股票名、持股数量、现价、浮盈亏（金额+百分比）

**交易历史表格：**
- 同样卡片化

---

### 3.9 每日复盘 (Review.tsx)

- Markdown 内容为主，天然适配
- 日期选择器全宽
- 复盘数据卡片 `grid-cols-2`

---

### 3.10 订单簿 (OrderBook.tsx)

**买卖盘深度：**
- 桌面：买盘和卖盘左右并排
- 手机：买盘和卖盘上下排列，或 Tab 切换

---

### 3.11 数据管道 (DataPipeline.tsx)

- 操作按钮竖排排列
- 进度条和状态信息全宽
- 使用频率低，简单适配即可

---

### 3.12 股价预测 (Prediction.tsx)

- 参数输入竖排
- 预测图表全宽
- 预测结果卡片 `grid-cols-2`

---

### 3.13 新闻分析 (News.tsx)

- 新闻列表天然适配（卡片流）
- 情绪分析结果可能需要缩小字号

## 四、其他注意事项

### 4.1 viewport meta 标签
确保 `index.html` 中有：
```html
<meta name="viewport" content="width=device-width, initial-scale=1.0, viewport-fit=cover">
```
`viewport-fit=cover` 是为了正确处理 iPhone 刘海/底部安全区。

### 4.2 安全区适配
底部 Tab 栏需要加 `pb-[env(safe-area-inset-bottom)]`，防止被 iPhone 底部横条遮挡。

### 4.3 触摸优化
- 所有可点击元素最小 44x44px（Apple HIG 建议）
- 按钮之间保持足够间距，避免误触
- 表格行点击区域要大

### 4.4 不需要改的东西
- 后端 API 完全不需要改
- 路由结构不需要改
- 数据逻辑、状态管理不需要改
- 图表库（Lightweight Charts）原生支持触摸

## 五、实施优先级

按使用频率排序，建议分 3 批实施：

### 第一批（最常用，先搞定这些手机就能用了）
1. **Layout 底部 Tab 栏** — 没这个手机上无法导航
2. **实时行情** — 看盘入口
3. **K线分析** — 个股分析
4. **AI 顾问** — 随时问答

### 第二批（核心功能）
5. **信号分析** — 看信号
6. **交易记录** — 看持仓和盈亏
7. **新闻分析** — 看新闻

### 第三批（低频使用）
8. 策略回测
9. AI 报告
10. 信号追踪
11. 每日复盘
12. 订单簿
13. 数据管道
14. 股价预测

## 六、预估改动量

| 组件 | 改动程度 | 说明 |
|------|---------|------|
| Layout.tsx | **大** | 新增底部 Tab 栏 + 更多抽屉，桌面端条件隐藏 |
| Realtime.tsx | **中** | 卡片化表格 + 响应式网格 |
| Market.tsx | **小** | 主要是输入区域竖排 + 图表高度 |
| Advisor.tsx | **小** | 输入框位置调整 |
| Signals.tsx | **中** | 卡片化 + 筛选区改版 |
| Portfolio.tsx | **大** | 两个表格需要卡片化 |
| 其余页面 | **小~中** | 通用规则套用即可 |
