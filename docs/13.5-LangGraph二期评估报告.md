## 3. 四大安全件的图中挂载方案（逐件，难度分级）

| 安全件 | 当前形态 | 挂载方案 | 难度 |
|---|---|---|---|
| **历史压缩** `history.py::compact_history` | **无状态纯函数**，turn 开局调一次、就地改 `session.messages` | 图入口**前置节点**，对 `State.messages` 做变换。唯一约束：必须跑在 TurnMonitor 重建**之前**（下标漂移，`turn_setup.py:174`） | 🟢 **低**（几乎零障碍） |
| **TurnMonitor** `turn_monitor.py` | 轮级 dataclass，`pre_round` 已是「读状态→返回事件列表→不 yield」的中间件形态 | 作为 `State` 的可变字段 + 一个 **pre-round 条件节点**（budget_stop→强制收尾边）。`check_duplicate`/`record_result` 作节点内调用 | 🟡 **中**。风险=`ToolCallRecord.msg_index` 是 `messages` 下标，L4 轮中压缩靠它就地改 content；图若用 messages reducer 追加，下标语义会脆弱，需锁定「messages 用整体替换而非 reducer 追加」 |
| **会话锁** `context.py::run_lock` | `threading.Lock`，**完全在 API 层**（`agent.py:58` 拿锁/409、`_drain` finally 放锁），orchestrator 零耦合 | **原样留在 API/入口层，不进 State**（Lock 不可序列化）。图只读 `cancel_event` | 🟡 **中**。本身不难，但见 §5 风险①：与「确认中断持久化」的并发保证有张力 |
| **确认门** `confirm_gate.py` | **双入口 + 生成器 return 式中断**：`intercept` 命中即 `yield 事件` 后**结束 `_loop` 生成器**，靠 `session.pending_tool_call`（内存态、故意不落盘）撑着，`resume_with_confirmation` 是独立第二入口 | 用 `interrupt()` 原语建模「暂停等前端」，`Command(resume=approved)` 续跑 | 🔴 **高**。语义变化最大：当前是「丢弃循环栈、从零重进」，interrupt 是「保存/恢复图执行位置」；`resume` 里的 `record_result`+决策留痕+重进主循环这条**侧路必须在图里复刻**；`tool_call_id` 双开窗口防误批（`confirm_gate.py:61`）必须进 interrupt 的 resume 校验；**下单路径不落盘的 fail-safe**（重启作废 pending）与 checkpointer 持久化中断态直接冲突，需重新对齐 |

**小结**：history 🟢 / TurnMonitor 🟡 / run_lock 🟡 / 确认门 🔴。**确认门是主循环迁移的真正命门**——它承载下单确认这条最不能出错的路径，且当前语义与 LangGraph interrupt 差异最大。

## 4. 三深任务迁子图的收益/成本（逐个）

### 4.1 alpha_lab — ✅ 最佳试点（收益最高、形状最匹配）
- **控制流已是 evaluator-optimizer**：`engine.py:138 start_session` 的 `for i in range(1, max_iterations+1)` = 生成代码→AST 检查→沙箱回测→评估→迭代，几乎 **1:1 映射 LangGraph 循环子图**（`generate→execute→evaluate→(loop/early-stop)`）。
- **Evaluator 已是纯代码 + 明确 rubric**（`evaluator.py`：过拟合检测 `1-val_sharpe/train_sharpe` 阈值 0.3/0.5 + composite_score）——正好符合「cheap/确定性 evaluator」纪律，直接搬。
- **checkpointer 价值最高**：任务长（max_iter≤20、烧钱有 cost 累计）、`SessionState.messages` 是内存态，**进程重启/断连后无法从第 i 轮恢复**（现状无 resume 入口）。落 checkpointer 正好补上这个洞——这是 LangGraph 能带来的**真实新能力**，不是重写换重写。
- **成本/难点**：沙箱子进程回测的临时文件副作用要在节点边界管理；cancel 需从 subagent 包装层（`subagents/alpha_lab.py:75` 轮间 break）下沉到图中断。

### 4.2 report 章节 — 🟡 收益在「外层 DAG」，不在章内循环
- 章内 `write_section` 的 `for call in calls` 是 **`build_section_calls` 预先静态展开**的分批 LLM 调用，**无 LLM 规划需求**，checkpointer 价值低（正文不落库、每章几十秒可直接重跑）。
- 真正适合 LangGraph 的是**上一层**：五章 + 纵览的 **DAG 并发编排**（现靠主 agent 顺序调 report_* subagent）→ `Plan(选章)→Execute(并发5章)→Evaluate(纵览一致性)`，顺带还 P5 动态编排债。
- **难点**：流式 chunk 必须逐字到用户 + Ch8 章内批次链式去重状态 + relay 语义（正文全量给用户/仅截断摘要回灌）都要在子图节点保留。

### 4.3 deep_stock — ❌ 建议不迁
- 它是**复用主循环 `run_isolated` 的 mini-ReAct**（窄工具集 6 个只读工具的按需取数），**非 Plan/Execute/Evaluate**，无 evaluator/rubric/迭代收敛。
- 任务短（几轮工具调用收尾）、cancel 已下沉内层、无 checkpointer 需求。
- **强套子图 = 在 LangGraph 里把成熟的 `_loop` harness（参数校验/风控/TurnMonitor/policy_checks/trace）重建一遍，净损失**；且会丢掉 LLM 自主 ReAct 的按需取数（正是为对抗 v1「一次性塞 11 段」而设计）。**保持现状**。

### 不可变边界（三者共同）
无论子图内部是否用 LangGraph，对外**必须仍产出 `base.py` 的 NDJSON + 恰好一个 `subagent_done(ToolEnvelope)` 信封**，否则与主循环 `tool_dispatch`/`policy_checks` 断裂。这是迁移的硬边界，不容改动。

## 5. 风险清单

1. **确认中断持久化 vs 并发锁 vs 下单 fail-safe（最高风险）**：当前确认中断时 `run_lock` 在第一次请求结束就释放、pending 靠内存 session 撑、重启即作废（防跨重启误下单）。若 checkpointer 持久化中断态，这三条假设全变，必须重新设计「谁保证 resume 期间无并发」+「持久化的 pending 下单要不要跨重启复活」。**下单路径出错代价最高**，这条不理清不能迁主循环。
2. **msg_index 下标语义**：TurnMonitor/历史压缩都靠 `messages` 下标就地改 content；LangGraph 惯用 messages reducer 追加会破坏下标。缓解=State 里 messages 用整体替换语义。
3. **流式契约回归**：主循环/子代理全靠 NDJSON 逐字流 + `bridge_sync_stream`。图节点产出若不逐字透传，前端体验回退。
4. **测试重写成本**：21 个 tests/agents 是针对生成器 harness 写的，迁图后要重写为图测试，回归网短暂变薄。
5. **薄用纪律漂移**：LangGraph 生态诱惑大，一旦引入 chains/预制 agent 就违反 §6，需 code review 门禁盯死。

## 7. 推荐路线

**分期、opt-in、以 ROI 排序，随时可停**：

1. **先做 A（alpha_lab 试点）**——这是唯一「形状已匹配 + checkpointer 带来真实新能力（断点续跑）+ 不碰下单/确认高危路径」的单点。它能同时验证 LangGraph 在本项目的四原语薄用可行性，且失败可回滚（子任务级、有信号驱动的 execute_backtest 边界）。
2. A 验证满意后，**可选做 B（report DAG）**——顺手还 P5 动态编排债，收益是并发提速 + 纵览一致性 evaluator。
3. **C（主循环迁图）默认不做**：自研 harness 成熟、四安全件里确认门 🔴 + 下单 fail-safe/并发重设计是高风险，ROI 不足以对冲。仅当 A、B 都证明 LangGraph 在本项目稳定、且出现「主循环确需断点续跑」的真实需求时，再单独立项评估。
4. **deep_stock 永久保持现状**（ReAct 与 P/E/E 形状不匹配，迁移是净损失）。

**一句话**：LangGraph 在本项目的正当场景是**深任务断点续跑（alpha_lab 最典型）**，不是替换能用的主循环。薄用四原语、单点试迁、按 ROI 分期，是最稳的路。
